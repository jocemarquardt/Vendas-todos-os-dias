# Dados das campanhas

Coloque nesta pasta os relatórios exportados do Gerenciador de Anúncios.

## Como exportar (Meta Ads)

1. Abra o Gerenciador de Anúncios e selecione **todas** as campanhas (inclusive as pausadas).
2. Período: **últimos 90 dias** (ou desde o início, se for menos).
3. Faça 3 exportações em CSV/Excel, uma em cada aba:
   - `campanhas.csv` (aba Campanhas)
   - `conjuntos.csv` (aba Conjuntos de anúncios)
   - `anuncios.csv` (aba Anúncios)
4. Colunas importantes:
   - Valor gasto, Impressões, Alcance, Frequência
   - CPM, CTR (taxa de cliques no link), CPC (custo por clique no link)
   - Visualizações da página de destino
   - Adições ao carrinho, Finalizações de compra iniciadas, Compras
   - Custo por compra, Valor de conversão da compra, ROAS
   - Objetivo, Orçamento, Público, Posicionamentos
5. Se possível, uma exportação extra **por dia** (detalhamento: Tempo > Dia) para ver a consistência das vendas.

Se usar outra plataforma (Google, TikTok), exporte o equivalente com os mesmos nomes de arquivo mais o prefixo da plataforma, por exemplo `google-campanhas.csv`.

Prints de tela também servem: salve como `print-1.png`, `print-2.png`…
